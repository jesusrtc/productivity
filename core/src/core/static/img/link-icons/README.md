# Link service icons

Bundled locally so opening Lab never requests third-party favicons.

Google Docs, Sheets, Slides, and Forms PNGs are the official Google product icons:
`https://www.gstatic.com/images/branding/product/2x/{docs,sheets,slides,forms}_2020q4_48dp.png`.

Other SVGs come from the Iconify Logos collection (SVG Logos by Gil Barbara, CC0):
https://raw.githubusercontent.com/iconify/icon-sets/b91a0d48b331b0fead8edb259c973c7faa269552/json/logos.json

https://github.com/gilbarbara/logos/blob/master/LICENSE.txt

Brand marks remain the property of their respective owners. GitHub, Notion, and
Linear use CSS masks to remain legible in both light and dark themes.

`../../link-services.json` is the shared service registry for URL detection in the
link editor and backend. Specific URL rules precede broad domain matches.
