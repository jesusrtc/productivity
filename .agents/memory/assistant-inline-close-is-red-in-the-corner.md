# Inline document close is visible in the upper-right corner

The user wants the active document's close button at the upper-right corner of
the document in Assistant, separated visually from Preview/Save/Revert/Copy and
Expand. Use a red icon, tinted background and border, visible keyboard focus,
and a larger touch target on mobile. Anchor it to the shared inline header and
reserve space so titles/actions cannot overlap it at narrow widths. Preserve
the existing draft/autosave close handler.
