# Terminal Objective groups expand one at a time

Only the current Objective's terminal rows are expanded. Keep all focused
Objective headers visible, with a fold indicator. Clicking a terminal Objective
header or choosing an Objective in the top dropdown selects the same Objective
state and folds every other group. An empty Objective still keeps New available.
Folding changes navigation chrome, preserving sessions and their processes.

This supersedes the visible inactive rows described in
`inactive-objective-terminals-only-color-headers.md`. Keep the existing task
ordering, colors, compact/full rail behavior and whole-Objective activation.
The Home Objective demo follows the same folding behavior.
