# Demo task list is navigation-only

In Home → Objectives demo, the user wants the left task list for navigation,
with completion and editing in the middle task view. Clicking a task opens
task mode with its name/icon, completion toggle and red corner close; retain
that header while browsing task assets. Expand only one parent task's children
at a time. Clicking another task collapses the previous group. Asset attachment
and the explicitly requested asset-to-task-icon drop remain available there.
