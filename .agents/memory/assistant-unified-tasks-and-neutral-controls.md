# Assistant uses one cross-workspace list and neutral controls

On September 15, 2026 the user requested a minimalist Assistant UI with
comfortable click targets. This extends the earlier compact-header preference.

- Show tasks from all mapped workspaces together by default. Put a quiet
  workspace label on each row and offer a workspace filter (e.g. Pikaboo),
  composed with the other filters. Do not restore separate workspace tabs or
  automatically scope the list to the first workspace or an opened task.
- Keep recurrence out of the main task rows, including missing-date notices.
  Edit it in the document header using Once, Weekly, Monthly, or Yearly;
  Once clears recurrence.
- Favor neutral colors for priority/status labels, selected documents, and
  controls. Reserve color for meaningful urgency, blocked/overdue work, or errors.
- Minimal does not mean tiny buttons: use 36px top copy/filter controls and
  32px section-copy/metadata targets with readable labels. Preserve the
  content-only main document pane for both tasks and notes.
