# Sidebar picker supports worktree and folder search words

The user wants a clearly colored Git branch icon and Worktree badge in the project picker. Whole search words branch/worktree (including plurals) filter to worktrees; main/master filter to folders and parent folders, regardless of the primary checkout branch. Combine these words with ordinary name/path search, preserving usage order. Path segments such as /trees/main remain ordinary substring searches.
