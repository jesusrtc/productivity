# Assistant section copy uses the heading context menu

The user prefers no Slack/GDoc copy buttons beside Markdown headings. In
Assistant tasks, notes and subtabs, secondary-click a heading to choose the
single Copy content action. Always use the Google Docs rich copy payload,
which also works in Slack. Preserve the live disclosure state and section
boundaries through LabMarkdown.copy. Generate content retains its behavior of
copying only the prepared artifact, without the wrapper heading.

The main document toolbar's whole-document copy controls are separate.
Headings support Shift+F10; Escape dismisses the menu before the document.
