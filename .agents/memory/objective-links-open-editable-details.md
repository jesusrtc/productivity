# Objective links open editable details

The user wants ordinary Objective link clicks to open the actual URL in the
clicking browser, preserving the working area. Cmd/Ctrl-click shows title,
URL, TL;DR and editable named metadata in the middle working area. This applies
to shared/worktree links, nested sublinks and task asset links.
Save/Cmd-Ctrl-S persists
the details; Revert loads the saved fields. Keep navigation drafts and reject
stale saves without discarding them. The explicit Open button visits the valid
edited URL. Reuse the
service-aware icons and domain mappings. Optional metadata fields need no
registry migration and do not change shared/worktree ownership or Assistant.

This supersedes iframe opening for Objective links only. Existing ordinary
folder/worktree links retain their separate external-view behavior.
