# Objective links open editable details

The user wants ordinary Objective link clicks to show title, URL, TL;DR and
editable named metadata in the middle working area. Save/Cmd-Ctrl-S persists
the details; Revert loads the saved fields. Keep navigation drafts and reject
stale saves without discarding them. Open and Cmd/Ctrl-click open directly in
the clicking browser, preserving the center on modified clicks. Reuse the
service-aware icons and domain mappings. Optional metadata fields need no
registry migration and do not change shared/worktree ownership or Assistant.

This supersedes iframe opening for Objective links only. Existing ordinary
folder/worktree links retain their separate external-view behavior.
