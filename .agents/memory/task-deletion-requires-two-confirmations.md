# Task deletion requires two confirmations

The user requested on October 9, 2026 a Delete task operation that removes the
entire branch and associated terminals/assets, with double confirmation and
typing the task name. Review the branch first, then require the exact canonical
task title in a separate dialog. The server checks confirmation, reviewed
registry revision and an owned-content review token before destructive work.

Delete recursive task records, exclusive owned documents/notebooks or tabs,
exclusive asset registrations, linked primary terminals, inherited extra
terminals, Lab terminal history and automation launch records. Protect fixed
main terminals, terminals owned by surviving tasks, shared assets, sibling and
unrelated document content. Preserve external source files/documents and
worktree folders; remove task associations. These source-preservation defaults
were stated to the user while implementing the feature. Running notebooks must
finish first. Refused cleanup or failed writes must restore staged task content.
