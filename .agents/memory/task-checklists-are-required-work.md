# Task checklists are required work

Markdown checklists are consequential, well-defined action items. Show completed
and pending counts and prevent task completion while required items remain
pending. Objective details tabs and explicit Assistant task tab links own these
items; inherited navigation does not invent checklist ownership. Agents must
not invent scope, add filler, tick unverified work or delete items to claim
completion. Preserve wording and require user authorization to change scope.
This guidance belongs in the shipped Lab context available to every workspace.
