# Workspace new-tab button

Keep a small, plain + button immediately after the open top-level tabs. The
picker has no Open vault action. Existing workspaces appear in separate groups
headed by the owning vault name and color, with an All vaults / specific vault
filter. New workspace uses the filtered vault or asks for a vault when showing
all groups. The create form captures the selected vault when opened so navigation
cannot redirect the creation request to another vault.
