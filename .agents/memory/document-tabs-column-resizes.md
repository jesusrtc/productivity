# Document tabs column resizes

The user wants room to widen or narrow the document tabs column. Use a visible
draggable divider in both inline and modal Assistant/workspace document views.
Remember the chosen width in browser storage across documents, allowing
160–720 pixels while leaving a strip of content exposed to dismiss the drawer.
Default to 420px in inline and modal views. Support keyboard resizing and
double-click to reset. Preserve drafts while resizing; mobile keeps its
horizontal tabs without a vertical divider.
