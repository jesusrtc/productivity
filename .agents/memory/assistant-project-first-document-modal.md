# Assistant is project-first with a task document modal

- Never mix tasks from different mapped Lab projects in one task list. The top
  task control selects exactly one Lab project and shows its unique attention
  count.
- Inside the selected Lab project, group tasks by the task's internal `group`
  metadata and reveal a group's task rows on click.
- Every task row shows an explicit TLDR and opens its full modal on a single
  click. This supersedes the older single-click inline preview interaction.
- The task modal is a document browser: the main task and every first-class
  subtask Markdown file are selectable in the same left rail.
