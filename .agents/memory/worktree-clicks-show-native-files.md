# Worktree clicks show native Files

The user wants a single click on a worktree to select its native Files tree,
with Recently updated, vs main and Uncommitted controls intact. Never open
the folder modal as a follow-up to ordinary Root, Objective or worktree scope
navigation. Exit task focus and save outgoing drafts even when the checkout
was already selected. Preserve filter preferences, cached trees and all task
groups. Explicit GitHub/history, terminal or metadata actions retain their
separate UI; the scope label itself only navigates files.

This supersedes the folder-browser-on-scope-click rule in
objective-first-navigation-and-overview.md. The Objective heading continues
to open its asset/task overview; worktree clicks open Files instead.
