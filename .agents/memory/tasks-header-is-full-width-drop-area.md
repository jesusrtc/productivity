# Tasks header is a full-width drop area

The user wants Tasks to offer a visible full-width drop area comparable to task
rows, not just its small text label. Highlight the whole header and accept drops
on its label, blank area, progress badge or add button. Dropping a task or its
primary terminal promotes the task branch to the Objective's top level with IDs,
assets, worktree colors and terminal ownership intact. Unowned terminal drops
retain the existing Tasks-view association behavior. Never send terminal input
on these drops.
