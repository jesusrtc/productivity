# Terminal tabs use folder badges

Session-list badges show Home/Logs/vault section names on Home, and the linked
folder alias (or `main`) inside workspaces. Use the Home badge's colored dot,
not the old vertical scope bar or CODEX/TERMINAL text. The agent icon remains.
Mark worktrees explicitly, using a compact branch symbol in narrow rows; keep
the complete worktree name/path in the tooltip. Folder aliases follow local
sidebar settings, with saved scope labels as the fallback.

This supersedes the left-edge accent in `terminal-project-worktree-links.md`.
