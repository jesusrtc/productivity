# Automation terminals show white bullets when folded

The October 8 correction in [Compact terminals use computers and corner dots](compact-terminals-use-computers-and-corner-dots.md)
supersedes centered compact bullets with computer icons and small corner dots.

The user clarified on October 7, 2026: show one white bullet for each automation
terminal when the terminal rail is folded. Hide its name until expansion, where
the saved name stays white without a bullet. A stopped automation may also show
its explicit relaunch control. Apply the same
marker to compact horizontal tabs. Use the theme's primary text color so the
marker remains readable in light mode. Preserve nested positions, selection,
hover expansion, task context and accessible terminal labels.

This supersedes the always-visible compact names in
[Automation terminal tabs show only white names](automation-terminal-tabs-show-only-white-names.md).
