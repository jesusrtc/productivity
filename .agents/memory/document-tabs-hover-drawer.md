# Document tabs reveal on hover

The user wants document tabs hidden behind a slim vertical strip at the left
edge. Hover reveals the full navigation drawer; moving back into content after
selection hides it. Overlay the content so reading position does not shift.
Preserve the resizable width from document-tabs-column-resizes.md, keyboard
access and Escape dismissal. Keep a visible document → nested tab → heading
reference, updating the heading on scroll. Desktop inline and modal views share
this behavior; mobile keeps its horizontal navigation.
