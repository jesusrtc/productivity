# Vaults are sections inside Home

Vaults (such as Local and SSD) appear only in Home's section navigation,
alongside Overview, Code Search, and Admin. Selecting a vault keeps the Home
top-level tab active and the Home section bar visible. Do not recreate vault
tabs in the top bar or its new-tab picker. Workspace tabs still open separately
and retain their owning vault identity. The vault view keeps its own file and
terminal scope; existing `?view=vault&vault=...` links remain supported.

This supersedes the top-level vault-tab wording in the earlier cross-vault
navigation and Focus mode memories.
