# Document-linked terminals use the document icon

A terminal linked to an Assistant document or one of its tasks uses the same
cyan document glyph (▤) as the Documents / Linked documents sidebar. Apply it
through the shared terminal visual helper so tabs, compact rails, and the active
header agree. The document association takes precedence over a linked file's
icon, matching the document-title precedence. Preserve provider identity and
working/completion indicators; unlinking restores the ordinary provider or
linked-file icon. This applies equally to Codex, Claude, and Copilot.
