# Terminal worktree colors stay local

The user clarified that moving a checkpoint terminal/task must not turn other
terminal names blue. Ordinary names, including Objective mains, remain neutral.
Only names associated with a specific worktree use that worktree's color, such
as checkpoint blue or sdui red. Objective headers/dividers retain their colors;
automation and merged display-main names retain their existing explicit styles.
This supersedes objective-terminal-names-follow-objective-color.md.
