# Push changes to main by default

- For this Lab repository, push completed work to `origin/main` by default.
- Only push to a different branch when the user explicitly requests that branch or explicitly says not to push to main.
- Do not create pull requests for completed work. The user explicitly reaffirmed on September 30, 2026: "No prs push directly to main always". Commit and push directly to `main` unless a later user instruction changes this preference.
