# Task worktrees have their own section

Task mode shows assigned checkouts in a Worktrees section immediately below
Task assets. Exclude whole checkout references from the Task assets rows; keep
Root/Objective folders and checkout subfolders as ordinary assets. Show only the
selected task's explicit, non-archived checkout assignments, preserving their
colors, actions, drag/drop, stars, terminal links and context references. Keep
an empty Worktrees section for a selected task with no checkout assignments.

This supersedes the task asset presentation in
`worktrees-follow-task-asset-buckets.md`; stored assignments remain unchanged.
