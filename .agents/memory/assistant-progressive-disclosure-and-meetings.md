# Assistant uses progressive disclosure and meeting notes

- The user prefers compact, minimalist lists over permanently visible detail panes.
- The current Assistant interaction opens the complete task document modal on a
  single task-row click; it no longer uses an inline preview/double-click split.
- Tasks expose Markdown checkboxes as individually tracked subtasks; a parent may
  not become done while any subtask remains open.
- Meeting notes are a first-class Assistant tab with Summary, Highlights, Action
  items, and Notes sections.
