# Linked terminals show the file name and icon

File-linked terminals use the file basename before the project fallback and
the shared sidebar file-type icon in both the terminal tab and active header.
Keep the filename label on worktree tabs too; folder/worktree badges still
provide scope. Explicit terminal renames remain respected. Compact rails keep
the file icon and expose the filename in the active header and hover details.
This supersedes the file-label rule in `terminal-tabs-show-project-names.md`.
