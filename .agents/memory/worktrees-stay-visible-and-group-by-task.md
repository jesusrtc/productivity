# Worktrees stay visible and group by task

The user wants every associated worktree in the sidebar Worktrees section,
regardless of which task is selected or whether the checkout is assigned.
Root and Objective folders remain first and gray. Other worktrees group by
Unassigned, Objective-pinned or their assigned task/subtask; a checkout shared
by multiple tasks appears once under a combined label. Preserve actual task
memberships, shared stars, contextual asset references, source paths, worktree
drop targets and running terminal ownership. Archive remains collapsed and
recoverable in the Worktrees section.

This supersedes the fixed-root-only navigation rule in
worktrees-follow-task-asset-buckets.md. The overview-only rule for unassigned
assets in objective-assets-use-reviewed-assignments.md does not hide worktree
navigation. Switching tasks or opening a document/folder must keep the full
active worktree list available.
