Lab Focus mode keeps the 48px topbar visible so Home and all open workspace
and project tabs remain usable while fullscreen is active. It hides only the
project attributes bar; the Overview/repository strip, diff strip, sidebar,
terminal panel, and framework/workspace views retain offsets below the topbar.
