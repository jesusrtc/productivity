metadata:

Lab Focus mode keeps the 48px topbar visible so Home and all open vault
and workspace tabs remain usable while fullscreen is active. It hides only the
workspace attributes bar; the Overview/repository strip, diff strip, sidebar,
terminal panel, and framework/vault views retain offsets below the topbar.
