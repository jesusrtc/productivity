# Logs is a Home section

Logs sits immediately before Admin in Home’s section bar. Its full-page viewer
has Errors, Backend, and Frontend in a left source selector, with live updates,
copy, and clear for the selected consolidated log across registered vaults.
Clear deletes the stored history, including entries outside the displayed tail.
The shared Home terminal stays mounted while CSS hides it behind this view.
Use `?view=productivity&subview=logs`; old `?view=logs` links and error alerts
also open this section. Logs no longer lives inside Admin.

This supersedes the Admin location in `sidebar-recent-diagnostics-and-log-controls.md`.
