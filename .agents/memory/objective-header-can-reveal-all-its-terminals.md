# Objective headers can reveal all their terminals

Put a Show all button beside the active Objective header in terminal tabs, with
an accessible ☰ button in the compact rail. It reveals every status, independent
session and task recommendation in that Objective while other Objectives stay
folded. Show WIP restores In progress plus the selected task. Keep the selected
task, center view and active terminal unchanged; do not create or kill sessions.
Save this preference separately per Objective and workspace in browser view
state, restore it on reload, and retain keyboard focus when toggling.

The global Show all terminals action remains in + New and fixed-main menus.
When that mode already reveals everything, the Objective control says All shown.
