# Child terminal expansion is saved

Every parent terminal, including automation parents, has a small expand/collapse
button visible only while the terminal names/details are visible. Clicking pins
its children open or returns them to folded/temporary disclosure. Save the choice
per parent in the browser's workspace/vault group state and restore it after
refresh and reload. Nested parents keep independent choices.

Hover still reveals children temporarily after one second and never persists
that reveal. Preserve existing active-family and own-In-progress visibility,
session selection and identity, context menus, recovery controls and compact
icon positions. The toggle supports keyboard use and lab ui control discovery.
