# Demo document subtabs have temporary sidebar visibility

The user wants document/Markdown subtabs revealed beneath the document after
one or two seconds of hovering. The Objectives demo uses 1.5 seconds. Clicking
a subtab opens it in the working area as its own document. Revealed subtabs
stay in the sidebar for five minutes; individually pinned subtabs remain
until unpinned. A click also refreshes the five-minute visibility window.
Pin state and the expiry timestamp belong only to the demo's browser storage.
Terminal links may target a document subtab without changing the terminal's
worktree folder. This prototype does not alter real Assistant documents.
