# Task rail icons stay in place

The October 13, 2026 request extends the terminal rail's stable icon geometry
to Tasks in the first column. Folding/hover expansion must leave task and
subtask icons at exactly the same height and horizontal position, with the same
size. Keep recurring markers fixed too. Preserve the layout of Objective
headings, worktrees and pinned assets above Tasks so they cannot shift the list.

Use the same custom/default icon on the left in both states. Expanded custom
rows retain a status control on the right; title indentation shows hierarchy
without moving the icon lane. Compact icons still navigate and expanded icon
controls still open customization. Verify actual production markup with pinned
assets, nested tasks, open worktrees, scrolling and different drawer widths.
This supersedes the separate compact icon presentation in
collapsed-task-navigation-keeps-icons.md while preserving its navigation rule.
