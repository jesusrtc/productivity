# Terminal Objective headers provide context and switch sections

Only the active Objective's terminal rows unfold, including with global **Show
all terminals** enabled. Show all changes status filtering and exposes parked
Objective headers; it must not expand their terminals. Clicking a terminal
Objective header selects that Objective, unfolds its terminals and folds the
previous section. Headers remain available for navigation; sessions keep running.

The Objective main row reads **Main**, without repeating its Objective name.
Generated terminal labels and folder badges also omit a repeated Objective
name supplied by the heading. Preserve custom terminal labels, distinct
worktree names and full folder tooltip paths.

This supersedes the unfold-every-Objective behavior in
terminal-menu-can-reveal-all-objectives.md and reinforces
terminal-objective-groups-expand-one-at-a-time.md.
