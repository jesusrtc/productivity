# Collapsed task navigation keeps icons

The October 9, 2026 full-window screenshot identifies the left Objective task
navigation rail, separate from the terminal switcher. Each collapsed task row
must show its custom icon or its default task status emoji and remain clickable
for opening the task. Expanded rows retain their status badge, title and icon
picker controls. Keep recurring markers small and worktree title bullets folded.

The compact drawer hides task buttons. After status badges became buttons,
that rule hid all task icons. A dedicated compact icon avoids tying navigation
visibility to the expanded customization controls. Native checks must exercise
the production task markup inside the actual sidebar drawer.
