# Compact project location rows

Workspace File sidebar settings list projects as compact inline rows with their
name, color, and Location/Worktrees buttons labeled Default or Custom. Keep all
paths hidden until the corresponding button is clicked. The project picker
lists project names and default/custom status, without exposing raw paths.
Default includes explicit paths equal to the configured default after home/path
normalization. Opening a location editor does not save or move anything.
