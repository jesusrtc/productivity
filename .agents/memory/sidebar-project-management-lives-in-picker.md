# Sidebar project management lives in the picker

The user wants projects and worktrees managed directly through the sidebar + picker, pins, and color controls. Remove the duplicate Workspace projects list, location editors, Add project picker, and Worktree colors section from workspace File sidebar Settings. Saving the remaining file preferences must preserve existing scope selections, pins, colors, usage, and worktree paths. Global project/worktree folder defaults and allowed link types remain in Settings.
