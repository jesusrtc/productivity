# Agent files belong to requests and delegated assignments

The user wants double-clicking an agent terminal to show a document-style modal
of files that agent changed, grouped by user requests or assignments from a
parent/chief-of-staff LLM. These groups are separate from Objective tasks,
subtasks and checklists. Include delegated descendants with their own attribution.
Keep Rename in the context menu and preserve ordinary shell double-click rename.

All providers use shared packaged context/bootstrap/managed templates, never
handwritten client-specific AGENTS additions. Teach work start, exact file
reporting and result summaries. Parents pass relevant authorized user context,
decisions, constraints, permitted file scope and expected results to children;
children resume their linked assignment and repeat the workflow if delegation
is authorized. Do not copy raw conversations or infer authorship from the whole
Git dirty set. History is explicit attribution; previews show current files,
not archived versions, and missing paths retain their records.
