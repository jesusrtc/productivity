# Grouped rows show stars from both notes and series

A filled star on a collapsed series means its series or at least one member
note is starred. Clicking it exposes separate Entire series and Latest note
toggles; View starred notes opens the existing document-modal history with the
starred filter. Never silently star/unstar a series because one note changed,
or erase individual note stars when un-starring the series.

Starred must include regular notes/tasks when its type filter is unrestricted.
The user's recurring-only Starred filter caused standalone starred notes to stay
in Documents; that restriction was explicitly removed while fixing the report.
Keep custom filters authoritative, and keep one row per series.
