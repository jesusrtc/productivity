# File modal browses sibling files

Double-clicking a sidebar file opens the existing document modal with that file
selected and its folder’s other files in a left column. Cmd-click (or Ctrl-click)
on a real sidebar folder opens the same modal with a file selection prompt,
without changing the folder’s expansion state. Fetch siblings from the actual
folder, independent of Recently updated filters; retain the sidebar’s hidden-file
preference and the selected workspace/worktree root.
