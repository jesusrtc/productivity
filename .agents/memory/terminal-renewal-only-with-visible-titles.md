# Terminal renewal only with visible titles

The October 9, 2026 follow-up requires the ↻ refresh/renewal button only while
terminal titles are visible. Hide it when the vertical rail collapses or the
horizontal tabs become compact. Keep task emojis and custom icons visible in
compact mode. Display renewal beside the expanded title without shifting or
resizing the existing icons and markers.

This refines the renewal-control visibility in
[Terminal rail reveals titles without moving icons](terminal-rail-reveals-titles-without-moving-icons.md).
