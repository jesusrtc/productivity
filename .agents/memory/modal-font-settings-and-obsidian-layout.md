# Modal fonts and Obsidian-style settings

The user wants larger document text and settings arranged like Obsidian: a
searchable sidebar, labeled rows, compact controls, and toggle switches.
Settings → Global → Appearance has separate browser-local controls for document
text (12–32 px, default 18) and modal interface text (12–24 px, default 14).
Font changes apply and persist immediately, with a live preview and individual
resets. Other settings retain explicit Save changes and captured workspace scopes.

Apply document sizing to both Markdown and editors, including their highlight
or changed-line overlays. Blank editor lines must scale with the line height.
Keep terminal rendering and non-modal document views independent of these sizes.
