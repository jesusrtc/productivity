# Terminal task links open the highlighted task

The client wants the associated task visible and directly accessible from its
terminal. Show a clickable accent label on the terminal tab and context header;
open the existing document modal over the current workspace without navigation
or process creation. Resolve the document by immutable ID and Assistant database,
select the task's own or inherited content tab, and reveal/highlight the exact
JSON task even when nested or completed. Preserve saved display preferences and
allow the user to collapse the revealed branch again.

Keep the original terminal selected underneath and show the same linked session
in the modal. A document-only association opens the remembered document tab.
