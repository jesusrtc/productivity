# Client issues can use diagnostic scripts

When the user reports an issue that occurs in their client environment, Codex
may provide a focused diagnostic script for the user to execute there and ask
them to return its output. Prefer a short, read-only script that captures the
specific runtime state needed to replace guesswork with evidence, explains what
it collects, avoids secrets and unrelated data, and is easy to paste or save and
run. Use the returned output to continue the investigation.
