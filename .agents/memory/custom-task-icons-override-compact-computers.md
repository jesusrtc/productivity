# Custom task icons override compact computers

On October 8, 2026 the user clarified that the compact computer-icon redesign
must honor existing custom task icons. Use the saved asset icon on task primary
terminals, inherited child/process terminals and recommended task launch rows.
Use a computer only as the fallback. Merged tabs inherit the parent's custom
icon, while their actual console and activity belong to the selected child.

Keep compact icons centered, status/worktree dots in the corner and the rail
visually flat. Expanded automation rows keep names and live activity dots;
their inherited custom task icon appears only in the compact rail.
