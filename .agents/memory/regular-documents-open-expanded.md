# Regular documents open expanded by default

The user wants the regular document open to use the expanded workspace layout:
hide Files temporarily, extend the document into that area, and keep the active
workspace's existing terminal panel beside it. A single click or keyboard open
must use this behavior, without requiring Expand, double-click or Command-click.
Apply the same default to Assistant entries, linked/recent sidebar documents,
folder/worktree internal document and tab links, terminal task labels/activation,
programmatic normal opens and deep links. The normal header needs no Expand button.

Preserve red corner close, drafts, terminal session/input, active workspace,
request cancellation and saved Files visibility. Explicit inline API compatibility
can remain, but normal UI entry points must not request it. This supersedes the
regular inline default in assistant-documents-open-inline.md and documents-preserve-files-sidebar.md.
