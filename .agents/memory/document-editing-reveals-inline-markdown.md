# Document editing reveals inline Markdown

The user wants a Notion / Google Docs style editing surface backed by Markdown.
Keep the document formatted while typing, and reveal delimiters or a link's
source only at the caret's inline span or selection. Do not switch an entire
paragraph or block to raw Markdown. This supersedes the whole-block reveal in
document-live-markdown-autosave.md; its saving and independent-tab rules remain.

Use readable document typography, editable headings/lists/tables/code, native
caret placement and undo, clickable task checkboxes, selection formatting
controls and Cmd/Ctrl+B, I and E shortcuts. Markdown remains the stored source.
Complex preview clicks must map to the clicked text. Keep the current tab's
10-second idle autosave, conflict protection, saved history and sibling bodies.
