# Workspace objectives use All plus five focus tabs

The user replaced workspace Overview with All and five objective slots in the
workspace subnavigation. Use the small colored-dot vault-tab appearance and
objective names. Remove the earlier objective selectors from the sidebar;
Tasks starts that column. All lists every saved objective, with name/outcome
search, focused/parked and task-status filters, creation and focus selection.
Dragging from All targets the exact slot; a parked objective replaces an
occupied slot without deleting its data. Dragging between filled slots swaps
them. Empty slots stay clickable and droppable. Five is the new workspace
focus limit; the separate Home browser demo is still independent.

The version-1 registry keeps ordered `focused` IDs, allowing null vacancies.
Focus actions accept zero-based slots 0–4 and preserve checkout/resource/task
ownership. Older three-slot registries remain readable. Reserve distinct
project palettes, retaining older checkout colors when a reused project color
needs a new palette on refocus. Startup/poll dashboard refreshes must preserve
newer All/task/editor views.

Workspace Code Search, Jupyter, Logs and Cleanup buttons are removed; declared
server tabs remain. Notebooks open through resources/Files. Logs and Cleanup
are global header controls next to each other.
