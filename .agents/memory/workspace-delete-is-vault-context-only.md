# Workspace deletion starts in the vault list

The user wants a red Delete workspace action on secondary click in each vault's
Workspaces list. That action opens the workspace with a red DELETE WORKSPACE
button beside Focus mode. Keep the button hidden on normal navigation, when
leaving the workspace, and after reload; never persist or URL-enable delete mode.
The button asks for explicit confirmation naming the exact folder and warning
that all contained files are permanently lost before deletion.
