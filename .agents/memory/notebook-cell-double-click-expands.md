# Double-click a notebook cell to expand it

Double-clicking a saved notebook cell's header or rendered content opens the
same file modal as its Expand button, at that stable cell with the existing
brief blue highlight. Keep editable fields, links, and embedded controls usable;
do not expand unsaved draft cells or reopen cells already inside the modal.
The binding belongs to the notebook container so it covers newly rendered cells
and remains usable after the modal closes.
