# Assistant documents open inline by default

Single-click document rows in Assistant and workspace sidebars to open the
shared document editor in the main file area. Double-click opens the modal;
Expand still moves the same editor/draft into the modal. Keyboard activation
opens inline. Preserve last-tab memory, drafts, the existing terminal panel,
and the prior Files sidebar visibility when closing or navigating away.
Cancel delayed pointer opens and in-flight requests when leaving the view.

This supersedes the modal-by-default preference in assistant-document-tasks.md.
