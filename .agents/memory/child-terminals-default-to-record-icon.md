# Child terminals default to record icon

On October 9, 2026 the user chose ⏺ as the default child-terminal emoji in both
compact and expanded lists. Ordinary task terminals retain 💻, workspace main
retains 🏠 and Objective main retains 🎯. Saved custom icons take precedence,
including inherited task icons. Merged tabs retain their displayed parent's
identity. This is presentation only; do not change session ownership or hierarchy.
