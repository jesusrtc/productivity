# Vault → Workspace → Terminal

The user chose Vault for the registered storage root (Local, SSD), Workspace for a persistent Lab work area opened in a top-level tab, and Terminal for a shell or agent terminal. Tab describes navigation; session describes a running process or resumable conversation. Apply this terminology consistently to UI text, commands, APIs, variables, CSS, filenames, configuration, tests, and documentation. Legacy names belong only at compatibility boundaries and in external provider formats.
