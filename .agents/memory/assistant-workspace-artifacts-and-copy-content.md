# Assistant keeps workspaces contextual and communications copy-ready

- Assistant workspace filters map to exact Lab vault/workspace paths, but task
  documents do not navigate directly into the owning workspace.
- Workspace-owned images may be referenced from task Markdown and rendered in the
  expanded preview and modal; the Assistant database does not copy the assets.
- `# Generate content` is the standard copy-ready communication section. The UI
  provides formatted and plain-text copy actions, while sending and completion
  remain deliberate manual steps.
