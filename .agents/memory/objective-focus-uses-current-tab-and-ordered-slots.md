# Objective focus uses one current tab and ordered slots

The latest Objective navigation is Objectives + the current objective in the
workspace bar. Hovering the current objective shows all five focused slots in
a dropdown; the arrow and keyboard also open it. Keep the menu outside the
scrolling tab strip so it is not clipped. Server tabs remain.

The Objectives library has five numbered slots above search/results. Dropping
a result inserts at that position, shifts later objectives down and parks the
previous fifth. Moving a focused objective first removes its old position;
never duplicate it. Keep the library open after placement. Parking preserves
all content and terminal associations. This supersedes five separate top tabs
and the former replacement/swap behavior.
