# Demo asset stars share Objective context

Every demo asset, including document subtabs and raw explorer files/folders,
has a star that toggles membership in shared Objective context. Starring and
unstarring preserve existing task associations. Dropping an asset onto a task's
icon area attaches it if needed and uses its icon for the task, current tab and
linked terminals. Clicking Unassigned opens the middle task list for asset
attachment drops.
