# Task sidebar omits Markdown actions

The left Objective Tasks panel is navigation for tasks and structured subtasks.
Do not append unchecked Markdown checklist/action items below task names there,
including in the compact drawer or after recurrence and background refreshes.
Do not reserve empty row space for those document actions.

Keep action items, deadlines, source links and highlights in the main Tasks
dashboard and the owning document. Their counts, completion requirements,
content and CLI representation remain intact. This supersedes the sidebar
action-list portion of `pending-task-actions-and-deadlines.md`.
