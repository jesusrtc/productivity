# Objective-first navigation and overview

The sidebar starts with a selectable, draggable Objective name and that
Objective's task list, ahead of its asset sections. This supersedes the
Unassigned-first order in live-objectives-use-task-asset-buckets.md. Shared
Objective assets, selected task assets, Unassigned, Archive and folder scopes
follow. Preserve the reserved task-list height during parent/subtask navigation.

Selecting an Objective exits task mode and opens a center overview of every
task/subtask and all active assets, including assets scoped to other worktrees.
Group global/shared assets, each task's details and attachments, Unassigned,
and the complete catalog; omit Archive. Keep the Home sandbox consistent.

Explicit Root/Objective/worktree selection must exit task focus and open the
exact folder browser even if that file scope was already selected. Otherwise
Focus can leave Files hidden and make the click appear ineffective. Save
outgoing drafts and guard asynchronous folder opens against later navigation.
