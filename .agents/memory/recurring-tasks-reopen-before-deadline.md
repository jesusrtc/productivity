# Recurring tasks reopen before the deadline

Workspace Objective and document-owned Assistant tasks can repeat automatically
every X days, weeks, months or years. Preserve the same task ID. After verified
completion, leave it done until the configured lead window before the next
calendar deadline, then reopen it and its existing checklist/subtasks. Default
lead: one day; allow minutes/hours (such as one hour for daily work). Keep real
unfinished overdue obligations rather than skipping them. Preserve the calendar
anchor across short months and deadline-time/window edits. Legacy Assistant
string recurrence retains its manual next-occurrence workflow.
