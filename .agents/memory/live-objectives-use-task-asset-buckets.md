# Live Objectives use task asset buckets

On October 3, 2026 the user asked why the real workspace still lacked the
left task list and linked assets, authorizing the workflow from the Home demo
in the live sidebar. This supersedes the demo-only restriction. Live order is
Unassigned, Objective pinned/shared assets, navigation-only Tasks, then selected
Task assets. Archive is recoverable below, followed by fixed gray roots and
worktrees. Stars share context without removing task associations. Only the
selected parent expands. Completion/editing live in the working task header,
which persists while opening native assets; red close exits task mode.
Optional shared/archive/shelf fields require no registry migration.

The later [worktree asset rule](worktrees-follow-task-asset-buckets.md) removes
explorer file/folder stars and places worktrees in the same asset buckets.
