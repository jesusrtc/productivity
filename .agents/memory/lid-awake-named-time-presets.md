# Lid Awake uses named time choices

The user wants **Overnight** (until 07:00), **Working time** (until 17:00),
and a third **Custom time** control. Show Working time first from 06:00
through 17:59 local time, and Overnight first from 18:00 through 05:59.
Refresh that suggestion whenever the menu opens, including after the page
has stayed open across a cutoff. The editable custom time starts with the
suggested deadline. Keep the 15, 30, and 60 minute shortcuts compact below.
All clock times use the existing next-local-occurrence timer behavior.
