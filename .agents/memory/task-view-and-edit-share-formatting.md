# Task View and Edit share formatting

The user prefers the native editor's formatting and wants task View to match it.
Share document column width, font family, line height, heading scales/weights,
strong text, links, task checkbox sizes, quote borders, code font and table
sizes across the live editor and rendered task preview. Keep rendered preview
paragraph spacing and text inset aligned with ordinary blank Markdown lines
in the editor. Scope semantic preview styles to Objective documents so other
workspace surfaces keep their typography.

View remains rendered read-only content; do not enable editing merely to get
the editor's appearance. The task document browser check compares computed
styles for all six headings, text formatting, quotes, code and tables, and
checks the same column geometry across View/Edit alongside its idle-lock tests.
