# Sidebar sections sort independently

Recently updated and Files each persist their own project-scoped sort mode.
Defaults are Updated descending for Recently updated and Name for Files; Type
sorts by extension and then filename. Folder rows stay ahead of files. In
Updated mode, folders are ordered by their newest descendant, while Name and
Type keep folders alphabetical. At narrow sidebar widths, each sort selector
gets a readable full-width row instead of collapsing to an arrow-only control.
