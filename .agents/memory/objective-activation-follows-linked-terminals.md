# Objective activation follows linked terminals

Selecting the whole Objective from the top bar or sidebar activates its
directly linked terminal and reveals the terminal panel, just as task clicks
do. Keep the current terminal if it belongs to that whole Objective; otherwise
choose the first available match. A task/subtask, asset, folder or Tasks-list
terminal is not a whole-Objective match.

Selecting a directly linked terminal opens its Objective overview and selects
the correct Objective in the top bar. Terminal-originated navigation must
not activate a second terminal. Passive view restoration and metadata refresh
must preserve terminal selection.
