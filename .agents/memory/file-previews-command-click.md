# Command-click applies across file previews

Command-click opens the file modal from rendered Markdown, text/code, JSON,
saved diffs, media surfaces, and same-origin HTML previews. Carry the clicked
character and full word across wrapping/inline markup, preserve expanded
Markdown disclosures, and briefly highlight the word in green. The cell outline
is exclusive to notebooks. Reuse the shared sibling-file modal and its saved
sort; retain the file's captured repository/worktree root. Embedded browser PDF
viewers do not expose their internal text or clicks to the parent document.
