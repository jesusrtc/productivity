# Whole Objectives pass reference context

The user wants to pass context for a whole Objective to an agent, analogous to
task and individual-item references. Drag its current tab, focus-menu entry,
left Objective heading or library row into a console. Include its outcome,
manifest and Objective folder, every task/subtask specification and attachment,
all active registered assets (including Unassigned and worktree-scoped assets),
exact document tabs and sublinks, and linked worktrees. Exclude Archive and
unregistered explorer files. Define each exact reference once while preserving
task/subtask roles. Block unavailable bundles rather than passing partial context.

Use the existing shared context formatter and terminal reference validation.
Paste an unsent prompt scoped to This objective; task drops remain scoped to
This task. Preserve focus-slot dragging and existing terminal associations.
The Home demo uses the same bundle and remains browser-only.
