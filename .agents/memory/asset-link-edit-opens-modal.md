# Asset link Edit opens a modal

The user wants asset links to offer **Edit** on secondary click. It opens a
modal over the current task or document, including for individual sublinks and
links in the Task assets dialog. Keep the underlying view and asset list in
place, retain drafts on close/Escape and preserve resource IDs, task assignments,
terminal targets, metadata and conflict checks when saving.

Normal clicks still open a pop-out; Command/Ctrl-click opens a browser tab.
This supersedes the Edit link details label and inline context-menu editor
described in markdown-and-asset-links-use-windows.md.
